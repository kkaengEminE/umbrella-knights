# 세 우산 기사단 · 비의 끝에서

파란우산(얼음), 검정우산(그림자), 찢어진 우산(가시)이 함께 모험하는 카툰 스타일 Canvas 2D 횡스크롤 액션 RPG 프로토타입입니다.

## 플레이

https://kkaengEminE.github.io/umbrella-knights/

PC 키보드용. 이동 ← → / A D, 방향키 두 번 대시, Space 2단 점프, J 약공격, K 강공격, U 막기, Q/E 순환 교대, L·O·P 고유 스킬, T 스킬 트리, F 대화, Esc 일시정지.

3개 스테이지와 보스, 마을 장비 공방, 스킬 습득·배치, 바닥 전리품 자동 획득, 브라우저 로컬 자동 저장을 지원합니다. 보스 진입 전에 선택하며 전투 중에는 퇴장할 수 없습니다. 마을 진입 후 이전 스테이지로 돌아갈 수 없습니다.

## 로컬 실행과 테스트

```sh
python3 -m http.server 4173 --directory dist
node tests/game.test.cjs
```

빌드 의존성 없이 `dist/`를 정적으로 배포합니다. 저장 데이터는 브라우저와 사이트 주소별로 분리됩니다.

## 캐릭터와 설정

시작 화면의 설정에서 설(여성·얼음), 무영(남성·그림자), 홍아(여성·가시)의 소개와 조작법·초반 이야기를 읽을 수 있습니다. 상세 제작 설정은 [CHARACTERS.md](CHARACTERS.md)를 참고하세요.

각자 HP를 가지며 음식은 선두만 회복합니다. 탈진한 동료는 교대에서 제외됩니다. 마을이나 전원 탈진 후 재도전 시 모두 회복합니다. 일시정지 중 날씨도 멈춥니다.


## 캐릭터 원화와 이야기
설·무영·홍아의 승인된 원화는 설정의 캐릭터 소개와 대화에 사용합니다. 설정화 전체는 원화 크게 보기로 열 수 있습니다. 전투에는 같은 디자인에서 만든 투명 카툰 아틀라스를 사용하며, 우산은 날씨·막기·공격에 따라 별도로 움직입니다. 현재 몸체는 정지 원화에 이동 흔들림과 방향 전환을 적용한 방식이며, 프레임별 달리기·베기 애니메이션은 후속 작업입니다.
세계관·초반 스토리에서 첫 만남, 홍아의 수선 이유, 첫종을 향하는 목적을 읽을 수 있습니다. 전체 제작 기준은 WORLD.md를 참고하세요.
원화: art/concepts/ (제작 프롬프트 포함). 런타임 자산: dist/assets/characters/. GitHub Pages용 동일 자산은 docs/assets/characters/에 보관합니다.

## 픽셀 전환 프로토타입
[sprite-lab.html](dist/sprite-lab.html)에서 설의 대기·달리기·약공격 초안을 프레임별로 확인할 수 있습니다. 게임 주소에 ?pixel=1을 붙이면 동일한 시트를 실제 전투에서 시험합니다. 기본 게임과 저장 형식은 그대로이며, 미제작 동작은 기존 그래픽으로 표시됩니다. 제작 규격과 전체 모션·스킬·배경 계획은 [PIXEL-PIPELINE.md](production/PIXEL-PIPELINE.md), 기계 판독용 명세는 dist/assets/pixel/animation-plan.json입니다.

## 픽셀 기본 버전 · 2026-10-19
기본 주소에서 픽셀 버전을 실행합니다. 비교용 이전 렌더러는 `?classic=1`에 남겨 둡니다. `sprite-lab.html`에서 각 캐릭터 동작을 확인합니다. 이동 우산은 0.24초 펼침·접힘, 달리기는 이동 시계, 일반 적은 발·공격 준비·피격 반동·소멸 효과를 사용합니다. 배경과 적은 도형 기반 픽셀 그래픽이며 상세 원화 수준의 최종 아트는 아닙니다.

검증: game.test.cjs, pixel.test.cjs, pixel-combat.test.cjs. 세 스테이지의 보스 진입부터 마을까지 상태 전환을 자동 검증했습니다. 장시간 사람 플레이에 의한 난이도 튜닝은 별도 과제입니다.
