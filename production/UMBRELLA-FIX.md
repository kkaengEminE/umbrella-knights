# 우산 구조 교정

Built-in imagegen으로 기존 그림을 편집했다. 기존 파일은 비교용으로 보존한다.

방어 편집 지시: 얼굴·복장·자세와 탈진 행을 유지한다. 손에서 우산 중심으로 이어지는 단일 수평 축, 적을 향한 볼록한 천, 캐릭터를 향한 오목한 안쪽, 끝부분의 짧은 촉을 표현한다. 중복 손잡이와 활처럼 보이는 구조를 제거한다. 파란 얼음·검은 안개·찢어진 빨간 천을 유지한다. 투명 배경.

소개 원화 편집 지시: 얼굴·복장·문구·레이아웃을 유지하고 펼친 우산만 교정한다. 단일 손잡이와 중심축, 바깥쪽 볼록한 천, 손잡이 방향의 오목한 살대 구조를 맞춘다. 설은 왼쪽 인물의 접힌 우산을 보존하고 아래 무기 설명의 펼친 우산만 수정한다.

게임에서 방어 이미지는 좌우 방향에 맞춰 함께 반전한다. 넓어진 우산이 옆 캐릭터 셀을 침범하지 않도록 클리핑 범위를 조정한다.
